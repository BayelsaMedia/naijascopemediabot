16. VOICE NOTE SUPPORT
    - When user sends a WhatsApp voice note, 
      transcribe it using a speech-to-text service
    - Process the transcribed text as a normal 
      message and respond intelligently
    - Reply: "🎤 Got your voice note! Here's what 
      I heard: [transcription] — [response]"

17. IMAGE FACT-CHECK
    - When user sends an image or screenshot, 
      analyze it using Groq vision capability
    - Respond with: REAL / FAKE / UNVERIFIED 
      + a short explanation
    - Tag: "📸 NaijaScope Fact-Check"

18. ANONYMOUS TIPLINE
    - Command: "send tip"
    - Bot opens a guided flow:
      Step 1: "What is your tip about?"
      Step 2: "Which location does this involve?"
      Step 3: "Any evidence? Send photo or type none"
    - Tip is saved to database and forwarded to 
      admin@bayelsamedia.com.ng automatically
    - User stays completely anonymous

19. LIVE BREAKING EVENT MODE
    - When admin sends command "BREAKING ON [topic]"
      bot enters live update mode for that topic
    - Every new update pushed to all subscribers
      with: "🔴 LIVE UPDATE: [topic] — [update]"
    - Admin sends "BREAKING OFF" to end live mode

20. NAIRA EXCHANGE RATE
    - Command: "dollar rate" or "exchange rate"
    - Fetches and returns:
      💵 CBN official rate
      💸 Parallel market rate
      📈 Change from yesterday

21. FLOOD & DISASTER ALERTS
    - Command: "flood alert"
    - Returns current flood risk status for 
      Bayelsa LGAs from available weather/govt APIs
    - Subscribed users automatically receive 
      flood alerts when risk level is HIGH
    - Tag location: Yenagoa, Ogbia, Sagbama etc.

22. SCHOLARSHIP & JOB ALERTS
    - Command: "opportunities"
    - Returns latest 3 scholarships/jobs from 
      NaijaScope opportunities section
    - Users can subscribe specifically to 
      opportunity alerts separately from news

23. POLITICIAN PROMISE TRACKER
    - Command: "track [politician name]"
    - Returns list of promises made vs kept/broken
      stored in the database
    - Admin can add/update promise records via 
      a special admin command

24. DAILY OPINION POLL
    - Every day at 9AM WAT, bot sends one poll 
      question to all subscribers as interactive 
      WhatsApp buttons
    - Tallies votes and publishes results on 
      bayelsamedia.com.ng automatically
    - Command: "poll" to see today's question

25. REPORT A STORY
    - Command: "report"
    - Guided flow for citizens to submit news:
      Step 1: "What happened?"
      Step 2: "Where exactly?"
      Step 3: "When did this happen?"
      Step 4: "Send a photo if you have one"
    - Saved to database + emailed to newsroom

26. CUSTOM KEYWORD ALERTS
    - Command: "alert me about [keyword]"
    - Bot saves keyword for that user's number
    - Whenever a new NaijaScope article contains 
      that keyword, bot notifies that user instantly
    - Command: "my alerts" to see active alerts
    - Command: "remove alert [keyword]" to delete
